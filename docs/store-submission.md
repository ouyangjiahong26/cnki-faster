# 商店上架操作手册

三商店手动上架的完整物料与步骤。产物从 [Releases](https://github.com/ouyangjiahong26/cnki-faster/releases)
下载：`cnki-faster-<版本>.zip`，manifest 在压缩包根目录，三商店与手动安装通用。

## 通用文案

- 名称（中文）：CNKI Faster 知网精简加速
- 名称（英文）：CNKI Faster
- 一句话简介：只保留文献信息与 PDF 下载，移除知网文献页的 AI 推荐、引文网络
  与广告，显著加速访问。
- 详细描述：

  > 打开知网文献详情页时，本扩展在页面脚本初始化之前移除 AI 推荐、核心文献
  > 推荐、引文网络、相关文献推荐、图书视频广告等模块，并在网络层拦截广告位
  > 脚本与统计埋点请求，只保留文献基本信息与 PDF、CAJ 下载，显著加快加载
  > 速度。
  >
  > 特性：
  >
  > - 七个拦截模块可逐项开关，修改即生效
  > - 支持高校图书馆 CARSI 代理访问（如国防科大），适配常见代理的域名倒序
  >   路径格式
  > - 页面右下角提供 PDF 下载快捷按钮与「查看完整页」逃生舱
  > - 开源（MIT），不收集任何数据，全部逻辑在本地执行

- 分类：生产力工具（Productivity）
- 语言：中文（zh-CN）
- 官网/支持页：仓库地址 https://github.com/ouyangjiahong26/cnki-faster

## 权限理由（审核必填，逐条照抄）

- `storage`：保存用户勾选的拦截模块开关，仅存本地，不上传。
- `tabs`：读取当前标签页地址以判断是否知网页面，并在修改设置后刷新页面。
- `declarativeNetRequest`：取消用户勾选模块对应的广告与统计请求。
- 主机权限 `*.cnki.net`、`*.cnki.com.cn`：知网页面内容精简与请求拦截。
- 主机权限 `*.nudt.edu.cn`：国防科技大学图书馆 CARSI 代理访问知网的场景，
  代理页面上内容与请求拦截同样生效。
- 主机权限 `hm.baidu.com`：知网页面嵌入的百度统计脚本会被请求层取消，
  仅用于拦截，不读取其数据。

## 隐私声明（三商店表单通用）

- 不收集、不存储、不传输任何用户数据
- 无统计、无埋点、无第三方 SDK
- 单一用途：精简知网文献详情页
- Firefox 侧 manifest 已声明 `data_collection_permissions: ["none"]`

## 截图要求与制作

| 商店 | 尺寸 | 数量 |
|------|------|------|
| AMO | 640×480 以上（Firefox 窗口截图） | 至少 1 张，建议 2 张 |
| Chrome Web Store | 1280×800 或 640×400 | 1 至 5 张 |
| Edge Add-ons | 1280×800 | 至少 1 张 |

建议两张：精简后的文献详情页（体现正文与右下角浮条）、设置面板。制作方法：
在 Firefox 打开任一知网文献页，页面右键选「截图」，或开发者工具的响应式
设计模式固定窗口宽度后截全页，再用系统工具裁剪到目标尺寸。截图前确认扩展
处于启用状态且模块全开。

## 分商店步骤

### AMO（addons.mozilla.org，免费）

1. 注册并登录 AMO 开发者账号（可直接用 Firefox 账号）。
2. 「提交新扩展」上传 zip，类型选「列在 mozilla.org 上」（listed）。
3. 填名称、简介（用上文文案）、分类、语言，上传截图。
4. 隐私政策表单按上文隐私声明填写，数据收集选「否」。
5. 提交后先过自动审核，通常数小时到数天完成人工抽审。
6. 通过后把商店链接回填 README 的「从商店安装」一节，并把仓库 homepage
   设为该链接。

### Chrome Web Store（一次性 5 美元注册费）

1. 注册开发者账号并支付注册费（一次性，信用卡）。
2. 「新建商品」上传 zip。
3. 商店资料：描述、分类、语言照上文填写；图形资产传截图与一个 128×128
   商店图标（可用知网页截图或仓库 logo 位补）。
4. 隐离隐私声明：三个合规项（不出售数据、不用于无关用途、不收集）全选
   「否」，逐条权限理由照上文填写。
5. 「分发」地区默认全部，受众选所有人。
6. 提交审核，数小时到数天。被拒时按驳回意见修改后重新提交，常见问题
   是权限理由描述不足。

### Edge Add-ons（免费）

1. 注册 Microsoft Partner Center 开发者账号。
2. 若 Chrome 商店已上架，可直接「从 Chrome Web Store 导入」带入元数据与
   包体；否则手动「创建新扩展」上传 zip。
3. 商店资料与隐私声明照上文填写。
4. 提交审核，通常一至数天。

## 发新版本流程

1. 改 `extension/manifest.json` 的 `version` 与 `CHANGELOG.md`，提 PR 合并。
2. 打 tag（如 `v0.2.1`）并推送，release 工作流自动出包并挂到 GitHub Release。
3. 到各商店后台的对应商品页「提交新版本」，上传新 zip，商店资料不变则
   直接提交审核。
